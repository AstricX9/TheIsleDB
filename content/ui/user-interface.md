## Overview

A **user interface (UI)** is the means through which a user interacts with a computer, application, or other electronic system. It enables users to provide input, navigate available functions, and receive information or feedback.

Most modern video games use a [graphical user interface (GUI)](https://en.wikipedia.org/wiki/Graphical_user_interface), which presents information through visual elements such as menus, buttons, icons, and indicators.

For further information, see [User interface — Wikipedia](https://en.wikipedia.org/wiki/User_interface).

## User interfaces in video games

In video games, the user interface allows players to navigate menus, configure settings, control their characters, and understand information presented by the game.

User interfaces commonly consist of interactive menus and a [heads-up display (HUD)](https://en.wikipedia.org/wiki/HUD_(video_games)). Menus provide access to settings and gameplay options, while HUD elements communicate important information without requiring the player to leave the game.

A well-designed interface communicates information clearly while minimising unnecessary distractions.

<a id="ui-in-the-isle"></a>
## User interface in The Isle

In *The Isle: Evrima*, the user interface plays an essential role in both character management and survival gameplay.

The interface allows players to select their dinosaur, customise its appearance, monitor survival statistics, manage mutations, and interact with other players.

During gameplay, the HUD provides information about vital needs such as hunger, thirst, stamina, and nutrients. Additional information is accessible through the character menu and other interfaces.

The game's interface communicates important survival information while keeping much of the player's attention on the surrounding environment.

## Interface components

The user interface in *The Isle: Evrima* consists of several interconnected systems that allow players to navigate the game, manage their dinosaurs, and monitor their surroundings.

These interfaces can be divided into three primary categories.

<a id="main-menus"></a>
### Main menus

The main menus provide access to the game's core functions, including server selection, dinosaur customisation, and configuration settings.

For more information, see [Main Menus](page.html?category=ui&slug=main-menus).

<a id="in-game-menus"></a>
### In-game menus

In-game menus allow players to access information and functions relating to their dinosaur, including character statistics, dietary requirements, mutations, and nesting.

For more information, see [In-game Menus](page.html?category=ui&slug=in-game-menus).

<a id="heads-up-display"></a>
### Heads-up display

The [heads-up display (HUD)](https://en.wikipedia.org/wiki/HUD_(video_games)) communicates important information during gameplay without requiring players to open additional menus.

This includes survival indicators, environmental information, and interaction prompts.

For more information, see [Heads-up Display](page.html?category=ui&slug=heads-up-display).
