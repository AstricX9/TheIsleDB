# Images Directory

This directory contains all image assets for The Isle Database.

## Directory Structure and Naming Convention

Each dinosaur should have its own subdirectory with a consistent naming pattern. Follow the existing structure:

```
images/
	dinosaur-name/
		profile.jpg
		gallery/
			image1.jpg
			image2.jpg
			...
		icons/
			diet-icon.png
			habitat-icon.png
			...
```

## Adding Images for a New Dinosaur

1. **Create a new directory** - Use lowercase dinosaur name (e.g., `carnotaurus/`, `tyrannosaurus/`)
2. **Follow the naming convention** - Use consistent file naming across all dinosaur directories
3. **Copy existing layout** - If a directory appears empty, replicate the structure from an existing dinosaur folder
4. **Maintain organization** - Keep profile images, gallery images, and icons in their respective subdirectories

## Image Guidelines

### File Naming
- Use descriptive, lowercase names with hyphens (e.g., `hunting-strategy.jpg`)
- Include the dinosaur name in group shots (e.g., `carnotaurus-vs-ceratosaurus.jpg`)
- Use consistent file extensions (prefer `.jpg` for photos, `.png` for graphics with transparency)

### Organization
- **Profile images** - Main dinosaur portrait/showcase image
- **Gallery** - Additional screenshots, artwork, and gameplay images
- **Icons** - Small graphics for stats, diet, habitat indicators

### Quality Standards
- Use high-resolution images when possible
- Optimize file sizes for web performance
- Maintain consistent aspect ratios within categories
- Ensure images are clear and relevant to the content
